# docs/paper/ — Setdrift Public Paper Tree

This directory is the D8-10 public paper tree: the acmart (`sigconf`) skeleton
for the MSR-targeted methodology paper (WRITE-02/DELIV-04). It is committed to
the public `repo/sica-plugin/` GitHub repo.

## What lives here

- `main.tex` — acmart sigconf skeleton with real section headings (D8-07):
  Introduction, Related Work, Methodology, Corpus Construction, Results,
  Threats to Validity, Conclusion. Phase 10 (DELIV-04) fills in the real
  content; this phase (08-04) only proves the toolchain end to end.
- `references.bib` — a **READ-ONLY, one-way mirror** of the canonical
  bibliography at `.planning/dissertation/references.bib`. **Never edit this
  copy in place** and **never register it as a second Zotero/Better BibTeX
  export target** — the private dissertation copy is the sole source of
  truth. When the canonical bib changes, re-copy it here:
  ```bash
  cp .planning/dissertation/references.bib repo/sica-plugin/docs/paper/references.bib
  ```
- `figures/cost-delta.png` (+ `.pdf`) — a **watermarked fixture figure**
  generated by the already-shipped `setdrift-eval figures --cost-delta
  --allow-fixtures` CLI path. It exists **solely to compile-smoke-test** the
  `\includegraphics` pipeline (WRITE-02's acceptance criterion). It is
  captioned "FIXTURE DATA" in `main.tex` and must **never** be copied into or
  referenced from the dissertation body (`.planning/dissertation/`) — Phase 9
  (FIG-01) produces the real, unwatermarked replacement.
- `main.pdf` — the compiled output of the 4-step build below, committed so
  the compile result is auditable without re-running LaTeX.

## Compile sequence

acmart's default bibliography style, `ACM-Reference-Format.bst`, is a
classic-BibTeX `.bst` file — the compile pipeline uses **`bibtex`, NOT
`biber`**. Skipping the second `pdflatex` pass after `bibtex` is the single
most common cause of `[?]` citation markers.

```bash
cd docs/paper
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```
