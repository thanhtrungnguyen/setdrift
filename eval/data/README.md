# eval/data/ — the gitignored wall (eval harness)

Everything in this directory is **ignored by git** except this README.
Mined corpus material and raw captures the eval harness produces live here and
**never** get committed. Same data wall as top-level `data/`, just nested under
`eval/`. See ../../DATA_POLICY.md.

Subfolders (created at runtime, all ignored):
- `corpus/` — labeled developer-prompt corpora (public GitBug-Java–derived; enterprise parking, if/when IP clears)
- `raw/` — raw captured / mined material before processing
